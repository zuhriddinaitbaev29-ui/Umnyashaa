О проекте

Этот проект создан для демонстрации возможностей современной веб-разработки. Он показывает весь путь: от идеи и дизайна до работающего сайта, который открывается по ссылке на любом устройстве.

01

Идея

Понять, что должен показать сайт и для кого он создаётся. Сформулировать цель и набросать структуру разделов.

02

Разработка

Сверстать интерфейс на HTML5 и Tailwind CSS, добавить интерактивность и проверить сайт на экранах разного размера.

03

Результат

Опубликовать сайт через GitHub и Vercel. Готовый проект доступен по ссылке и обновляется после каждого изменения кода.

Возможности

Шесть принципов, на которых построен сайт. Каждый из них можно проверить прямо сейчас на этой странице.

01

Современный интерфейс

Тёмная тема, крупная типографика и аккуратные карточки. На экране только то, что помогает понять проект.

02

Адаптивный дизайн

Сайт подстраивается под телефон, планшет, ноутбук и большой монитор. Сетка и размер текста меняются на каждом брейкпоинте.

03

Быстрая навигация

Закреплённое меню, плавная прокрутка к разделам и подсветка раздела, который сейчас на экране.

04

Интерактивность

Мобильное меню, анимации при прокрутке, демо-окно с переключением устройств и кнопка «Наверх».

05

Чистая структура

Семантическая разметка HTML5: header, main, section, footer. Весь код собран в одном файле index.html.

06

Современные технологии

Tailwind CSS для стилей, JavaScript для интерактивности, Git и GitHub для кода, Vercel для публикации.

Как создавался проект

Четыре этапа: от первой мысли до показа на Demo Day.

  1. 01

    Идея

    Выбор темы, определение аудитории и главной цели сайта.

  2. 02

    Планирование

    Структура разделов, выбор цветов и шрифтов, первый макет страницы.

  3. 03

    Разработка

    Вёрстка на HTML5 и Tailwind CSS, адаптивность, интерактивные элементы, исправление ошибок.

  4. 04

    Презентация

    Публикация на Vercel и показ готового проекта на IT Demo Day.

Проект в действии

Это живой макет сайта. Переключи устройство над окном, и интерфейс перестроится так же, как настоящая страница на телефоне, планшете или компьютере.

  • Сетка меняется под ширину экрана
  • Меню сворачивается в иконку на телефоне
  • Без единой картинки: всё сделано на HTML и Tailwind
